## Part 3: Common Task Chains
This section shows how to combine modules for common complex tasks.

### Email Processing Chain
Find and Process Email → Send Response with Attachments:
1. Email Reader (find email)
2. Email Classifier (analyze content)
3. Google Drive (find referenced files)
4. Response Generator (create response)
5. Email Sender (send with attachments)

### Document Processing Chain
Create and Share Document:
1. Document Management (create document)
2. Google Docs (edit content)
3. Google Drive (set permissions)
4. Email Sender (notify recipients)

### Web Data Collection Chain
Gather and Process Web Data:
1. Browser Headers (prepare request)
2. Web Scraper (collect data)
3. Data Cleaner (normalize data)
4. Report Generator (create report)

### Task Management Chain
Create and Track Project Tasks:
1. Email Classifier (analyze requirements)
2. Trello Integration (create board/cards)
3. Google Calendar (schedule deadlines)
4. Notification Module (send updates)

## Usage Guidelines
1. For single capabilities, use Part 1 to find the most appropriate module
2. For related tasks, check Part 2 to find modules that can handle multiple aspects
3. For complex operations, refer to Part 3 for proven module chains
4. Always verify module dependencies in module_capabilities.txt before chaining
