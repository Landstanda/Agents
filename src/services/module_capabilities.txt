MODULE CAPABILITIES AND INTEGRATION GUIDE
=====================================

This document provides detailed information about each module's capabilities, requirements, and integration patterns. Use this information to orchestrate module interactions and achieve complex tasks.

For each module below, you'll find:
1. Purpose: The main function and role of the module
2. Capabilities: List of operations/actions the module can perform
3. Required Input Parameters: Mandatory parameters and data types
4. Optional Input Parameters: Additional configurable parameters
5. Output Format: Expected return data structure
6. Dependencies: Required external services or authentication
7. Common Workflows: Typical usage patterns and examples
8. Error Handling: Module-specific errors and handling strategies

**** Global Best Practices ****
1. Always validate input parameters before passing to modules
2. Implement proper error handling and logging
3. Check authentication before operations
4. Monitor and respect rate limits
5. Handle asynchronous operations properly
6. Maintain state consistency across module chains
7. Clean up resources after use
8. Log all critical operations and errors
9. Implement retry mechanisms for transient failures
10. Use appropriate timeouts for external service calls
